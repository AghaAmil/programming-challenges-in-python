# Tip Calculator Project

## Description

Create a simple Python program that calculates how much each person should pay when a bill is split between multiple people and a tip is added.

The program should:

- Display a welcome message for the Tip Calculator.
- Ask the user for the total bill amount.
- Ask the user for the tip percentage.
- Ask the user how many people will split the bill.
- Calculate each person's share.
- Print the amount each person should pay.

## Output

Your program output should look like this:

```text
=============================
Welcome to the Tip Calculator
=============================

Enter the total Bill: $150 (User's input)
Enter the tip in percentage (like 10%, 15%, 20%): 12 (User's input)
Enter the number of people to split the bill: 5 (User's input)
Each person should pay $33.6
```

> [!NOTE] Note
> Beware of the spacing and new lines in the program output.

## Background Knowledge

To solve this challenge, you should be comfortable with beginner Python concepts related to terminal programs, user interaction, numeric values, and simple calculations.

Helpful topics to review before starting:

- Displaying messages in the terminal.
- Receiving information from a user.
- Storing user-provided values so they can be used later.
- Working with whole numbers and decimal numbers.
- Performing basic arithmetic calculations.
- Understanding how spacing and line breaks affect what appears in the terminal.
