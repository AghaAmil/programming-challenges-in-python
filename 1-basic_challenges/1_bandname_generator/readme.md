# Band Name Generator Project

## Description

Create a simple Python program that generates a band name by combining the name of the city where the user grew up with the name of a pet.

The program should:

- Display a welcome message for the Band Name Generator.
- Ask the user which city they grew up in.
- Ask the user for the name of a pet.
- Combine both answers into a possible band name.
- Print the generated band name.

## Output

Your program output should look like this:

```text
==================================
Welcome to the Band Name Generator
==================================

Which city did you grow up in?
London (User's input)
Write down a name of a pet and the name of your current pet?
Fluffy (User's input)

Your Band Name could be London Fluffy
```

> [!NOTE] Note
> Beware of the new lines in the program output.
> Make sure each input cursor appears on a new line when getting user's input.

## Background Knowledge

To solve this challenge, you should be comfortable with beginner Python concepts related to terminal programs, user interaction, and text output.

Helpful topics to review before starting:

- Displaying messages in the terminal.
- Receiving information from a user.
- Storing user-provided values so they can be used later.
- Working with text values in Python.
- Understanding how line breaks affect what appears in the terminal.
